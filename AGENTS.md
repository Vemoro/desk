# Hinweise für Coding-Agenten

Die Projektregeln stehen in [Entwicklung](docs/entwicklung.md), die Beitragswege in [Mitwirken](CONTRIBUTING.md), die Produktgrenzen und Board-Zustände auf der [Roadmap](docs/roadmap.md). Für Änderungen an der Oberfläche gilt [Desk-Gestaltung](DESIGN.md).

Prüfe Auftrag und Zielbasis vor der Arbeit. Schütze fremde Änderungen und nutze eine getrennte Testumgebung mit synthetischen Daten. Halte offene fachliche Entscheidungen fest. Veröffentliche Issues, PRs und Kommentare im vereinbarten Auftrag. Merge und Release brauchen die Freigabe des Maintainers.

| Aufgabe | Skill |
| --- | --- |
| Issues schreiben und zum Review übergeben | [desk-issue-schreiben](.agents/skills/desk-issue-schreiben/SKILL.md) |
| Problem, Lösungswahl und Abnahme eines Issues unabhängig prüfen | [desk-issue-pruefen](.agents/skills/desk-issue-pruefen/SKILL.md) |
| Roadmap prüfen und Karten pflegen | [desk-board-pflegen](.agents/skills/desk-board-pflegen/SKILL.md) |
| PR vorbereiten und einreichen | [desk-beitrag](.agents/skills/desk-beitrag/SKILL.md) |
| Selbstprüfung und fachliche Beitragsprüfung | [desk-beitrag-pruefen](.agents/skills/desk-beitrag-pruefen/SKILL.md) |
| Unabhängiges Code-Review | [desk-tdd-review](.agents/skills/desk-tdd-review/SKILL.md) |
| Unabhängiges Doku-Review | [desk-doku-pruefen](.agents/skills/desk-doku-pruefen/SKILL.md) |
| Lokale Prüfungen isoliert ausführen | [desk-checks](.agents/skills/desk-checks/SKILL.md) |
| Seitenaufbau prüfen und neue Bereiche ohne passende Design- oder Codevorgaben vorbereiten | [desk-layout](.agents/skills/desk-layout/SKILL.md) |
| Vorher-Nachher-Aufnahmen vor der ersten UI-Änderung vorbereiten | [desk-pr-screenshots](.agents/skills/desk-pr-screenshots/SKILL.md) |
| Offene und gestapelte PRs zur Entscheidung aufbereiten | [desk-prs-pruefen](.agents/skills/desk-prs-pruefen/SKILL.md) |

Für die einmalige [Neubewertung des Bestands](docs/neubewertung.md) gilt die Regelbasis des ersten Merges. Die [Haben-Auswertung](docs/haben-uebernahme.md) hält die Herkunft und die Übernahmeentscheidungen fest.
